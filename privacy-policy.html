プライバシーポリシー

本アプリ「配管45°計算アプリ」（以下、「本アプリ」）は、ユーザーのプライバシーを保護するため、以下のとおりプライバシーポリシーを定めます。

1. 取得する情報

本アプリでは、広告配信、利用状況の分析、不正行為防止、セキュリティおよびコンプライアンスのため、以下の情報が収集・共有される場合があります。

（1）Google AdMob による広告配信

本アプリは、広告配信のために Google AdMob および Google Mobile Ads SDK を利用しています。Google Mobile Ads SDK 等により、次の情報が自動的に収集され、Google および広告配信・分析等に関係する第三者へ送信・共有される場合があります。

  • おおよその現在地：IP アドレス等から推定されるおおよその位置情報
  • アプリのインタラクション数：広告の表示・操作を含む、本アプリの利用状況や操作に関する情報
  • 診断情報：Google Mobile Ads SDK および本アプリの動作、エラー、パフォーマンス等に関する情報
  • デバイスまたはその他の ID：広告 ID（AAID）等のデバイスまたはその他の識別子

これらの情報は、本アプリの利用に伴って収集・共有される情報であり、一時的な処理に限らず取り扱われる場合があります。広告 ID 等は、個人の氏名そのものではありませんが、仮名識別子として取り扱われる場合があります。

Google による情報の取り扱いについては、Google プライバシーポリシーをご確認ください。

2. 利用目的

  • 広告配信およびマーケティング
  • 利用状況の分析
  • 不正行為防止
  • セキュリティ
  • コンプライアンス

おおよその現在地、アプリのインタラクション数、デバイスまたはその他の ID は、広告配信およびマーケティング、利用状況の分析、不正行為防止、セキュリティ、コンプライアンスのために利用される場合があります。

診断情報は、利用状況の分析、不正行為防止、セキュリティおよびコンプライアンスのために利用される場合があります。

3. 第三者への送信・共有

上記の情報は、Google Mobile Ads SDK 等を通じて、Google および広告配信・分析等に関係する第三者へ送信・共有される場合があります。また、法令に基づき開示が必要となる場合があります。

4. データの安全性

Google Mobile Ads SDK 等を通じて送信されるデータは、送信中に暗号化されます。

5. ユーザーアカウントおよびデータ削除について

本アプリには、ユーザーアカウントを作成する機能はありません。また、本アプリ内には、収集・共有されたデータの削除リクエストを受け付ける専用機能はありません。

6. 広告設定について

ユーザーは端末の設定より、広告識別子のリセットやパーソナライズド広告の無効化を行うことができます。

  • iOS：設定 → プライバシー → トラッキング
  • Android：設定 → Google → 広告

7. 免責事項

本アプリの利用によって生じたトラブル・損害について、開発者は一切の責任を負いません。 計算結果は参考値であり、施工条件により誤差が生じる場合があります。必ず現場環境に応じてご確認ください。

8. プライバシーポリシーの変更

本ポリシーの内容は予告なく変更される場合があります。変更後のポリシーは、本ページに掲載された時点で有効となります。
